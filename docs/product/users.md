# Usuarios objetivo

Este documento define para quien se esta construyendo el producto y que necesidades conviene priorizar primero.

## Usuario principal

La persona usuaria principal es alguien que quiere estudiar Biblia y teologia de forma estructurada, a su ritmo y con apoyo para mantener continuidad.

## Necesidades principales

- saber por donde empezar
- estudiar contenido ordenado en pasos comprensibles
- retomar facilmente el ultimo punto visto
- notar avance real y no solo consumir informacion
- tener una experiencia simple, sin friccion innecesaria

## Perfil esperado del usuario inicial

Para el MVP conviene pensar en una persona que:

- estudia de forma individual
- accede desde web
- valora mas la claridad del recorrido que la cantidad de funciones
- necesita estructura y seguimiento basico, no una plataforma academica compleja

## Roles secundarios previstos

Aunque el foco inmediato esta en el estudiante, a futuro el producto probablemente necesitara otros roles:

- persona administradora o editora de contenido
- persona mentora o responsable de seguimiento

Estos roles todavia no forman parte del alcance principal implementado.

## Implicaciones para el diseno

- la navegacion debe hacer visible el siguiente paso
- el progreso debe sentirse util y facil de interpretar
- el contenido debe presentarse en una jerarquia estable: curso, unidad y leccion
- la experiencia inicial debe funcionar bien antes de agregar logros o funciones avanzadas
