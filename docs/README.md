# Documentación del proyecto

Esta carpeta contiene la documentación viva del proyecto e-learning de teología.

La documentación se actualiza conforme se construye el sistema.

## Secciones

- `setup/`: instalación, configuración y ejecución del proyecto.
- `architecture/`: arquitectura general y decisiones técnicas.
- `database/`: modelos, relaciones, migraciones e índices.
- `api/`: endpoints, autenticación, errores y contratos.
- `decisions/`: decisiones importantes tomadas durante el desarrollo.

## Regla de documentación

Cada vez que se construya una funcionalidad importante, se debe actualizar el archivo correspondiente.

La documentación no debe inventar funcionalidades que todavía no existen. Si algo está planificado, debe indicarse claramente como planificado.
