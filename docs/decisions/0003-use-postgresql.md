# 0003 - Usar PostgreSQL como base de datos

## Estado

Aceptada.

## Decisión

Usar PostgreSQL como base de datos principal.

## Motivo

PostgreSQL es una base de datos relacional sólida, profesional y adecuada para aplicaciones con usuarios, progreso, contenido y relaciones complejas.

## Consecuencias

Django se conectará a PostgreSQL mediante su configuración de base de datos.

## Alternativas consideradas

- SQLite.
- MySQL.

## Conclusión

PostgreSQL será la base de datos principal.
